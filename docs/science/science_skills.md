# Science Skills
* ⭐ [AlphaFold](https://alphafold.ebi.ac.uk) - AI protein structure prediction tool to retrieve and analyze predicted structures for a protein.
* [AlphaGenome](https://deepmind.google.com/science/alphagenome) - AI genetic variant effects model to analyze variant effects on gene expression.
* [ChEMBL](https://www.ebi.ac.uk/chembl) - Query the ChEMBL database for bioactive molecules.
* [ClinicalTrials](https://clinicaltrials.gov) - Query ClinicalTrials.gov via APIv2.
* [ClinVar](https://www.ncbi.nlm.nih.gov/clinvar) - Clinical significance and pathogenicity classifications of variants.
* [dbSNP](https://www.ncbi.nlm.nih.gov/snp) - Search for short genetic variants (SNPs, indels) in dbSNP.
* [EMBL-EBI OLS](https://www.ebi.ac.uk/ols) - Search biomedical ontology terms.
* [ENCODE cCREs](https://screen.encodeproject.org) - Query cis-Regulatory Elements.
* [Foldseek](https://foldseek.com) - AI 3D structural protein similarity search.
* [gnomAD](https://gnomad.broadinstitute.org) - Query Genome Aggregation Database for allele frequency.
* [GTEx](https://gtexportal.org) - Genotype-Tissue Expression query tool for tissue RNA expression.
* [Human Protein Atlas](https://www.proteinatlas.org) - Semi-quantitative protein expression database.
* [InterPro](https://www.ebi.ac.uk/interpro) - Identify domains, families, and active sites in proteins.
* [JASPAR](https://jaspar.elixir.no) - Query Transcription Factor binding profiles and matrices.
* [arXiv Search](https://arxiv.org) - Literature search for physics and biology preprints.
* [bioRxiv Search](https://www.biorxiv.org) - Life sciences and biology preprint search tool.
* [Europe PMC](https://europepmc.org) - Scientific publications open-access full-text database.
* [OpenAlex](https://openalex.org) - Scholarly graph search for papers, authors, and citation indices.
* [NCBI Sequence Fetch](https://www.ncbi.nlm.nih.gov) - Retrieve protein and nucleotide sequences.
* [openFDA](https://open.fda.gov) - FDA adverse events, recalls, and approvals search.
* [Open Targets](https://www.opentargets.org) - Target-disease association drug discovery database.
* [PDB Database](https://www.rcsb.org) - Retrieve experimental 3D structures for biomolecules.
* [Clustal Omega MSA](https://www.ebi.ac.uk/Tools/msa/clustalo) - Multiple sequence alignment for proteins.
* [Sequence Similarity Search](https://blast.ncbi.nlm.nih.gov) - MMseqs2 and BLAST homology search.
* [PubMed Database](https://pubmed.ncbi.nlm.nih.gov) - Biomedical publications search.
* [PyMOL](https://pymol.org) - Visualise, analyze, and render protein 3D structures.
* [QuickGO](https://www.ebi.ac.uk/QuickGO) - Map genes to biological processes and GO terms.
* [Reactome](https://reactome.org) - Pathway analysis and exporter.
* [Science Skills Common](https://pypi.org/project/science-skills-common) - Shared rate-limiting client libraries.
* [STRING Database](https://string-db.org) - Query protein-protein interaction networks.
* [UCSC Conservation and TFBS](https://genome.ucsc.edu) - Evolutionary conservation scores and transcription factor binding sites.
* [UniBind Database](https://unibind.uio.no) - Database of direct transcription factor-DNA interactions.
* [UniProt Database](https://www.uniprot.org) - Access protein sequences and functional annotations.
* [uv tool](https://github.com/astral-sh/uv) - Fast Python package installer and resolver.
* [Workflow Skill Creator](https://github.com/google-deepmind) - AI assistant tool to package workflows into reusable skills.
