# Mobile Tools
* ⭐ [Android CLI](https://developer.android.com/studio/command-line) - Android build developer CLI tools to orchestrate Android development tasks including project creation.

* [Flutter SDK CLI](https://github.com/flutter/flutter) - Google cross-platform engine deploying native mobile, desktop, and web apps CLI.
* [Expo CLI](https://github.com/expo/expo) - React Native application local packaging and sandbox workflow CLI tool.
* [Fastlane CLI](https://github.com/fastlane/fastlane) - iOS and Android app store deployment and release lifecycle automator command line.
* [Android adb utility](https://developer.android.com/tools/adb) - Android Debug Bridge interface client executing shell commands on active devices.
* [Capacitor CLI](https://github.com/ionic-team/capacitor) - Native runtime bridge packaging web builds into iOS and Android apps CLI.
* [React Native CLI](https://github.com/react-native-community/cli) - Direct native wrapper compiling React codebases into native mobile binaries CLI.
* [Xcodebuild CLI](https://developer.apple.com/documentation/developer_tools) - macOS command line utility executing iOS builds, tests, and archive loops.
* [Ktlint CLI](https://github.com/pinterest/ktlint) - Kotlin compiler checking code styles and Android formatting rules CLI.
* [Swiftlint CLI](https://github.com/realm/SwiftLint) - Swift static compiler checking iOS style guidelines and safety warnings CLI.
* [Appium CLI](https://github.com/appium/appium) - Cross-platform test automation server for mobile app testing CLI.
