# Database Tools
* ⭐ [Firebase](https://firebase.google.com) - Manage Firebase projects, configure databases (Firestore, Realtime Database), deploy hosting/functions, and orchestrate Cloud Operations.

* [ClickHouse ClickPipes](https://clickhouse.com/docs/en/cloud/clickpipes) - Managed data ingestion service streaming database CDC, Kafka, and S3 data into ClickHouse Cloud.
* [Redis CLI](https://redis.io/docs/ui/cli/) - High-performance in-memory key-value database and cache publisher utility command line tool.
* [PostgreSQL CLI](https://www.postgresql.org/docs/current/app-pgdump.html) - Relational database backup engine and administrative SQL terminal query helper utility.
* [Supabase CLI](https://github.com/supabase/cli) - Local emulator stack manager, migrations generator, and Edge Functions deployer CLI.
* [Meilisearch API](https://github.com/meilisearch/meilisearch) - Ultra-fast, open-source instant search engine developer REST API.
* [SQLite CLI](https://www.sqlite.org/cli.html) - Local, zero-configuration SQL database engine administration terminal.
* [Prisma ORM](https://github.com/prisma/prisma) - Next-generation schema migrator and database client query generator ORM.
* [MongoDB Database API](https://github.com/mongodb/atlas-cli) - NoSQL document database cloud cluster configurations manager CLI and developer REST API.
* [InfluxDB CLI](https://github.com/influxdata/influx-cli) - Time-series metrics engine database administrator and query compiler CLI.
* [Neo4j Cypher Shell](https://github.com/neo4j/neo4j) - Graph database query console executing Cypher statements command line.
