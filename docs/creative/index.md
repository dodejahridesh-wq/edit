# Creative Skills
* [FFmpeg](https://ffmpeg.org) - Transcode, stream, filter, and edit video and audio files.
* [ImageMagick](https://imagemagick.org) - Create, edit, compose, and convert raster images.
* [Blender API](https://blender.org) - Blender 3D computer graphics scripting engine.
* [OpenCV](https://opencv.org) - Real-time computer vision frame manipulations and object detection.

* [Sharp](https://sharp.pixelplumbing.com) - High-performance Node.js image processing library powered by libvips, 4-5x faster than ImageMagick.
* [Pillow](https://python-pillow.org) - The friendly Python Imaging Library fork for fundamental image manipulation (crop, resize, filter, format conversion).
* [GIMP Script-Fu / Python-Fu](https://www.gimp.org) - Open-source raster image editor with Python 3 scripting API (GIMP 3.x uses GObject Introspection for full programmatic control).
* [HandBrake](https://handbrake.fr) - Open-source video transcoder with expert-tuned presets for high-quality encoding to MP4/MKV containers.

* [Three.js](https://threejs.org) - Client-side 3D WebGL library rendering GPU-accelerated graphics in browsers.
* [OpenSCAD](https://openscad.org) - Programmatic solid 3D CAD modeler reading descriptive script files.
* [Figma API](https://www.figma.com/developers/api) - Retrieval of UI design files, frame dimensions, component positions, and assets.
* [Canva API](https://www.canva.dev) - Design automation API to edit templates, upload assets, and export designs.
* [Inkscape CLI](https://inkscape.org) - Programmatic vector graphics manipulations and format conversions.
* [Audacity Scripting](https://manual.audacityteam.org/man/scripting.html) - Automation commands for editing and exporting audio projects in Audacity.
* [SoX (Sound eXchange)](https://sourceforge.net/projects/sox) - Command-line audio processing suite, effects generator, and transcoder.
* [SD WebUI API](https://github.com/AUTOMATIC1111/stable-diffusion-webui) - Local API endpoint for Stable Diffusion text-to-image and image-to-image.
* [Midjourney Bridges](https://www.midjourney.com) - AI art generation from text prompts.
* [Suno AI Bridges](https://suno.com) - AI music generation from textual style prompts.
* [Google Fonts API](https://developers.google.com/fonts) - Directory metadata feed for web font families and stylesheet imports.
* [Font Awesome API](https://fontawesome.com/docs/apis) - GraphQL API to query icon availability, SVG paths, and custom kits.
* [Librosa](https://librosa.org) - Python library for music and audio signal analysis (spectral, beat tracking).
* [WebAudio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API) - Low-level client-side browser API for audio synthesis, routing, and effects.
* [FFmpeg Filters](https://ffmpeg.org/ffmpeg-filters.html) - Direct programmatic video and audio matrix filter manipulation syntax.
