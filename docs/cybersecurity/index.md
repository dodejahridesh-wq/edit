# Cybersecurity Skills
* [Nmap](https://nmap.org) - Network discovery and vulnerability scanning tool.
* [OWASP ZAP](https://zaproxy.org) - Dynamic Application Security Testing (DAST) vulnerability scanner.
* [HashiCorp Vault](https://vaultproject.io) - Secrets management engine to store credentials and encrypt keys.
* [Shodan](https://shodan.io) - REST API search engine to discover Internet-connected devices, hosts, and vulnerabilities.
