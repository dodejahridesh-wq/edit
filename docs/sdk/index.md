# SDK Tools
* ⭐ [Google Antigravity SDK](https://github.com/google-deepmind) - Design, configure, run, and debug autonomous AI agents and multi-agent systems using the Google Antigravity (AGY) SDK.

* [Model Context Protocol (MCP)](https://github.com/modelcontextprotocol/servers) - Open-standard protocol connecting LLM assistants to databases, tools, and environments.
* [Claude Code CLI](https://github.com/anthropic/claude-code) - Anthropic terminal-native coding agent refactoring and running test suites CLI.
* [Ollama Server CLI](https://github.com/ollama/ollama) - Lightweight framework for compiling and running open LLMs locally CLI.
* [CrewAI SDK](https://github.com/crewai/crewai) - Python framework orchestrating groups of role-playing autonomous AI agents SDK.
* [AutoGen CLI](https://github.com/microsoft/autogen) - Microsoft multi-agent conversation orchestrator framework SDK command line.
* [Firecrawl API](https://github.com/firecrawl/firecrawl) - Web scraper rendering dynamic pages into LLM-clean Markdown and JSON formats API.
* [Llamafile CLI](https://github.com/Mozilla-Ocho/llamafile) - Mozilla silicified local LLM server and multi-architecture compiler CLI.
* [LangChain Python SDK](https://github.com/langchain-ai/langchain) - Direct orchestrator mapping models to indexes, chains, and agents library.
* [LlamaIndex Python SDK](https://github.com/run-llama/llama_index) - RAG framework connecting unstructured private data sources to LLMs SDK.
* [LiteLLM API Proxy](https://github.com/BerriAI/litellm) - Server proxying 100+ LLM APIs using a unified, OpenAI-compatible schema API.
