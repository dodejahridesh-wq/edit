# DevOps Skills
* [Docker](https://docs.docker.com) - Build, ship, and run containers; the industry-standard container runtime.
* [Kubernetes](https://kubernetes.io) - Automated container orchestration: deployment, scaling, and management of containerized applications.
* [Terraform](https://terraform.io) - Infrastructure as Code to provision and manage cloud infrastructure.
* [Prometheus](https://prometheus.io) - Prometheus HTTP API query endpoints and PromQL metrics query wrappers.

* [Podman](https://podman.io/) - Daemonless, rootless container engine — drop-in Docker alternative.
* [GitHub Actions](https://docs.github.com/en/actions) - Workflow automation built into GitHub for CI/CD, testing, and deployment.
* [Jenkins](https://www.jenkins.io/) - Open-source, self-hosted automation server for building, testing, and deploying software.

* [Ansible](https://www.ansible.com) - Agentless configuration management, application deployment, and task automation.
* [Pulumi](https://www.pulumi.com) - Infrastructure as Code utilizing real programming languages (TypeScript, Python, Go, C#).
* [GitLab CI/CD](https://docs.gitlab.com/ee/ci) - Multi-platform CI/CD runner pipelines built directly into GitLab.
* [Grafana](https://grafana.com) - Multi-source visualization dashboarding for metrics, logs, and traces.
* [Datadog](https://www.datadoghq.com) - Cloud-scale observability, APM tracking, and security monitoring.
* [ArgoCD](https://argoproj.github.io/cd) - Declarative GitOps continuous delivery tool tailored for Kubernetes.
* [Helm](https://helm.sh) - The standard Kubernetes package manager (Charts templating & releases).
* [Nomad](https://www.nomadproject.io) - Lightweight cluster scheduler and orchestrator for containerized and legacy apps.
* [Vagrant](https://www.vagrantup.com) - Declarative virtual machine environment builder and configurator.
* [AWS CLI](https://aws.amazon.com/cli) - Command-line management tool for Amazon Web Services services.
* [GCP gcloud CLI](https://cloud.google.com/sdk) - Command-line administration interface for Google Cloud Platform.
* [Azure CLI](https://learn.microsoft.com/en-us/cli/azure) - Command-line administration tool for Microsoft Azure resources.
* [Terraform Cloud](https://www.hashicorp.com/products/terraform/cloud) - Managed infrastructure execution, remote states, and workspace workflows.
* [Sentry](https://sentry.io) - Real-time application error tracking, crash reporting, and performance monitoring.
* [New Relic](https://newrelic.com) - Full-stack observability platform for telemetry data monitoring.
