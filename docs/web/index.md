# Web Tools
* ⭐ [Chrome DevTools](https://developer.chrome.com/docs/devtools) - Visual inspection, DOM manipulation, console debugging, network tracing, and automated web audits (Lighthouse) via Chrome DevTools MCP.
* [Modern Web Guidance](https://github.com/google-deepmind) - Implement premium web designs (rich aesthetics, glassmorphism, responsive grids), optimize Vite/Next.js bundle sizing, and attune CSS styling.

* [Playwright CLI](https://github.com/microsoft/playwright) - Chromium, Firefox, and WebKit end-to-end headless browser test runner CLI.
* [Puppeteer API](https://github.com/puppeteer/puppeteer) - Headless Chrome browser controller Node.js API library.
* [Lighthouse CLI](https://github.com/GoogleChrome/lighthouse) - Web page performance, accessibility, and SEO auditing engine command line.
* [Vite Compiler](https://github.com/vitejs/vite) - Next-generation frontend build tooling and hot-reloading developer server.
* [Tailwind CSS CLI](https://github.com/tailwindlabs/tailwindcss) - Fast utility-first CSS styling compiler and class trimmer tool.
* [Cypress Runner](https://github.com/cypress-io/cypress) - Frontend component and integration testing browser environment dashboard runner.
* [Astro CLI](https://github.com/withastro/astro) - Content-driven multi-framework static site generator and dev server CLI.
* [Next.js CLI](https://github.com/vercel/next.js) - Production React framework compiler, bundle exporter, and dev server CLI.
* [Webpack CLI](https://github.com/webpack/webpack-cli) - Modular asset bundler and code-splitting compiler command line client.
* [HTTPie CLI](https://github.com/httpie/httpie) - Modern, user-friendly command-line HTTP client for API debugging.
