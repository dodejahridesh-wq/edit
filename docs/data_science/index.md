# Data Science Skills
* [Hugging Face](https://huggingface.co) - Access and download pre-trained AI models, datasets, and pipelines.
* [DuckDB](https://duckdb.org) - In-process SQL OLAP database engine optimized for analytical queries.
* [TorchServe](https://pytorch.org/serve) - TorchServe model serving framework for deploying PyTorch models at scale.
* [JAX](https://jax.readthedocs.io) - High-performance numerical computing and accelerator compilation engine.

* [TensorFlow](https://www.tensorflow.org) - End-to-end open-source platform for building and deploying ML models
* [PyTorch](https://pytorch.org) - Flexible deep learning framework with dynamic computation graphs
* [scikit-learn](https://scikit-learn.org) - Classical ML library for classification, regression, clustering, and preprocessing
* [pandas](https://pandas.pydata.org) - De facto standard for tabular data manipulation and analysis in Python
* [Apache Spark](https://spark.apache.org) - Distributed data processing engine for large-scale analytics and ML pipelines
* [Polars](https://pola.rs) - Blazing-fast DataFrame library with multithreaded execution, written in Rust

* [Jupyter Notebook](https://jupyter.org) - Web-based interactive computing notebook interface supporting multiple languages.
* [Google Colab](https://colab.google) - Hosted Jupyter Notebook service with free access to hardware accelerators (GPUs/TPUs).
* [Weights & Biases](https://wandb.ai) - Machine learning experiment tracking, artifact versioning, and dataset lineage.
* [MLflow](https://mlflow.org) - Open-source platform for managing the end-to-end ML lifecycle.
* [Pinecone](https://www.pinecone.io) - Managed, serverless vector database optimized for semantic search and RAG.
* [Weaviate](https://weaviate.io) - Open-source vector database storing both data objects and vector embeddings.
* [ChromaDB](https://www.trychroma.com) - Lightweight, AI-native embedded open-source vector database.
* [Milvus](https://milvus.io) - Highly scalable, distributed open-source vector database for large vector sets.
* [Ray](https://www.ray.io) - Distributed compute framework for scaling AI models and Python workflows.
* [Dask](https://www.dask.org) - Flexible parallel computing library for analytics scaling in Python.
* [KServe](https://kserve.github.io) - Standardized model serving platform on Kubernetes (v1/v2 dataplane protocols).
* [HF Inference API](https://huggingface.co/docs/api-inference) - Serverless API to run model predictions on Hugging Face Hub models.
* [W&B Sweep](https://docs.wandb.ai/guides/sweeps) - Automated hyperparameter tuning and optimization orchestration.
* [Optuna](https://optuna.org) - Hyperparameter optimization framework with search space pruning logic.
* [Supabase Vector](https://supabase.com/vector) - Pgvector-backed vector database built on top of Postgres.
